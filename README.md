# Al Jojacha

Tovuq go'shti bo'yicha maslahatchi sayt (O'zbek, Русский, English). Server va tashqi AI kerak emas.

## WebStorm'da ochish
1. File -> Open -> `al-jojacha` papkasini tanlang.
2. `index.html` ustida o'ng tugma -> Open in -> Browser.

## Tuzilishi
- `index.html` - sahifa (hero, yon menyu, chat, o'ng panel, menyu)
- `css/style.css` - qizil-oq dizayn, mobil moslashuv
- `js/recipes.js` - 16 ta qo'shimcha taom retsepti (uz/ru/en)
- `js/kb.js` - bilimlar bazasi (KB: matnli javoblar, RC: retsept kartalari), uz/ru/en
- `js/engine.js` - til aniqlash, xatoga chidamli qidiruv, pishirish vaqti hisoblagichi, suhbat konteksti
- `js/art.js` - rasmlar (SVG)
- `js/app.js` - chat, profil, suhbatlar tarixi (brauzer xotirasida), til sozlamasi
